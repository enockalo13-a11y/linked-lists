# Linked Lists

Python implementation of the List ADT from Lecture 7 (Data Structures and Algorithms): Linear & Linked Lists.

- `ArrayList` - array implementation (0-based index)
- `SinglyLinkedList` - singly linked list (1-based position)
- `DoublyLinkedList` - doubly linked list (1-based position)

Operations: `is_empty`, `list_size`, `get`, `index_of` / `position_of`, `insert`, `delete`, `output`.

## Run

```
python linear_and_linked_lists.py
```

Running the file executes a demo of each list.
